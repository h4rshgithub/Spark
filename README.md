## ▶️ How to Run Java Programs

1. Install the JDK on your system.
2. Clone this repository:

   ```bash
   git clone <your-repository-url>
   ```

3. Navigate to the required folder.
4. Compile the Java file:

   ```bash
   javac Main.java
   ```

5. Run the program:

   ```bash
   java Main
   ```
